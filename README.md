# 🤖 AI Chatbot

An AI-powered chatbot built using Python, Streamlit, and Google Gemini.

## 🚀 Features

- 💬 Chat with an AI assistant
- 🤖 Powered by Google Gemini
- 🧠 Custom system prompts
- 💾 Database support
- 📱 WhatsApp integration
- 🌐 Simple Streamlit web interface

## 🛠️ Technologies Used

- Python
- Streamlit
- Google Gemini API
- SQLite
- Twilio
